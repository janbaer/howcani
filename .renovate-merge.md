# Renovate merge

## Before merge

1. Only when the current branch is `main` and more than one Renovate PR is open: ask whether several PRs should be merged in one go. If yes, ask which ones and whether a feature branch should be created for them.
   - With a feature branch: create `feature/renovate-batch` from `origin/main`, merge the selected PR heads into it locally, and run step 2 once on that branch. The PRs are still merged one by one on Forgejo afterwards. Delete the local branch when done.
   - Without: continue with the single PR picked.
2. Run `bun install` and `bun test --isolate` on the PR head (or on the feature branch). The working tree must be clean; check out the head detached and return to the previous branch afterwards, then run `bun install` again. If any test fails, the verdict is "do not merge": show the failure and stop.

## After merge

Nothing. Deployment is a separate step.
